# 数据处理说明

版本：1.0.1。更新日期：2026-10-10。

本扩展用于在 X 用户列表与信息流中显示用户粉丝数。

扩展在 `x.com` 和 `twitter.com` 页面中处理页面自身已发出的 JSON 响应，并从用户对象提取用户名和粉丝数。响应可能含有其他页面数据，扩展仅提取上述字段用于匹配用户和显示标签。

用户名与粉丝数只缓存在当前标签页内存中，缓存上限为 5,000 个用户；刷新或关闭标签页后清空。扩展不向开发者或第三方服务器上传数据，不读取 Cookie 或认证 Token，不主动发起额外 API 请求，不持久保存数据，也不用于广告或出售数据。

X 本身的页面请求由 X 页面发起，受其自身政策约束。

数据处理仅限于扩展公开说明的粉丝数展示功能。使用者可通过刷新/关闭页面清空缓存，或卸载扩展停止处理。

发布者：`felixwong1989`。

联系方式：[项目 Issues](https://github.com/felixwong1989/x-follower-count/issues)。请勿在公开 Issue 中上传 Cookie、Token、完整 HAR 或私人通信内容。

提交 Chrome Web Store 时，还需在开发者后台填写本说明的公开 URL，并根据最终代码如实填写隐私申报。
